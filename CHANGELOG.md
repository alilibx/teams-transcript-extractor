# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2025-04-15

### Added

- One-click transcript extraction from Microsoft Teams meetings
- Auto-scrolling through virtualized transcript lists
- Support for both Teams v1 and v2 DOM structures
- SharePoint recording transcript support
- Extraction validation: start/stop events, gap detection, timestamp ordering
- Extraction report header in downloaded files
- Dark-themed popup UI with progress bar and validation panel
- Shadow DOM traversal for nested Teams UI components
